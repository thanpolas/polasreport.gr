## Decision

### 1. Data source for Feature 4 (EU comparison)
Use the **European Commission Weekly Oil Bulletin** as the canonical source.

Do **not** spend time researching or testing third-party APIs or alternative data providers at this stage.

#### Rationale
- official EU source
- stable and credible
- good fit for the product's public-utility positioning
- avoids unnecessary source-evaluation work
- avoids introducing extra dependency or trust issues

#### Implementation direction
- build the EU comparison pipeline directly against the Weekly Oil Bulletin
- assume **weekly resolution** as a hard constraint
- normalize the source into the existing internal data model
- do not fabricate daily values from weekly data
- if interpolation or carry-forward is ever used for rendering, it must be visually and methodologically honest

#### Notes for implementation
- expected ingestion format can be CSV / XLS / XLSX depending on what the source currently provides
- build the importer to be resilient to minor structural changes in the source file
- isolate parsing logic in a dedicated script/module
- emit a clean intermediate CSV/JSON in the same style as the existing pipeline
- support at minimum:
  - Greece
  - EU average
  - Italy
  - Bulgaria
  - Romania
- support at minimum:
  - Unleaded 95
  - Diesel

#### UX implications
- this should not ship as a default overloaded multi-country chart
- keep Greece as the anchor series
- EU comparison should be introduced as a separate comparison mode or optional view
- visible comparison series must stay limited and curated

---

### 2. Priority order between Feature 5 and Feature 4
Implement **Feature 5 (Multiple Fuels)** first.

Feature 4 (EU comparison) should remain after that.

#### Rationale
Feature 5 is a high-value, low-risk frontend enhancement:
- all required fuel data already exists in the current JSON payload
- no new external source
- no new pipeline complexity
- no frequency mismatch
- fast implementation
- immediate UX value

Feature 4 is materially heavier:
- requires new external ingestion
- weekly data model
- normalization work
- comparison UX design
- higher risk of clutter and scope expansion

#### Updated execution order
1. EUR/USD normalization
2. Methodology clarification
3. Multiple Fuels
4. Lag analysis
5. EU comparison

#### Engineering guidance
Treat Feature 5 as the next quick win:
- reuse the current chart system
- add compact fuel switching controls
- avoid duplicating chart blocks
- preserve the existing layout and interaction model

Treat Feature 4 as a later pipeline-backed extension:
- implement only after the core chart UX is stable
- keep the first version small and curated
- do not attempt full-EU explorer behavior in the first pass
