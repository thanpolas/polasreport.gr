# Feature 4: EU Comparison Layer -- Implementation Plan

## Decision (preserved from prior discussion)

Use the **European Commission Weekly Oil Bulletin** as the canonical source. No third-party APIs.

---

## Data Source -- Verified

### Source file
- **URL**: `https://energy.ec.europa.eu/document/download/906e60ca-8b6a-44e7-8589-652854d2fd3f_en?filename=Weekly_Oil_Bulletin_Prices_History_maticni_4web.xlsx`
- **Format**: XLSX, ~4.2 MB
- **Sheet**: "Prices with taxes" (sheet1, 1086 rows)
- **Update frequency**: Weekly (published Thursdays, data as of Wednesdays)
- **Stable URL**: The historical file URL contains no date -- it is overwritten in-place each week with the full cumulative history. It has been stable for years.
- **Auth**: None required

### Data structure (verified by downloading and parsing the actual file)
- **Row 0**: Column headers using naming convention `{CC}_price_with_tax_{fuel}`
- **Row 1+**: Price data, one row per week
- **Date column**: Excel serial numbers, converted to ISO dates
- **Prices**: EUR per 1000 litres (divide by 1000 for EUR/litre)
- **Coverage**: 2005-01-03 to present (~1058 weekly rows)

### Columns we extract

| Column header | CSV name | Description |
|---|---|---|
| `EU_price_with_tax_euro95` | `eu_euro95` | EU average, Unleaded 95 |
| `EU_price_with_tax_diesel` | `eu_diesel` | EU average, Diesel |
| `GR_price_with_tax_euro95` | `gr_euro95` | Greece, Unleaded 95 |
| `GR_price_with_tax_diesel` | `gr_diesel` | Greece, Diesel |
| `IT_price_with_tax_euro95` | `it_euro95` | Italy, Unleaded 95 |
| `IT_price_with_tax_diesel` | `it_diesel` | Italy, Diesel |
| `BG_price_with_tax_euro95` | `bg_euro95` | Bulgaria, Unleaded 95 |
| `BG_price_with_tax_diesel` | `bg_diesel` | Bulgaria, Diesel |
| `RO_price_with_tax_euro95` | `ro_euro95` | Romania, Unleaded 95 |
| `RO_price_with_tax_diesel` | `ro_diesel` | Romania, Diesel |

### Verified data quality
- Greece March 16, 2026: `gr_euro95 = 1.924` -- exact match with our daily data
- Bulgaria and Romania data starts ~2007 (empty before that, expected)
- All 10 columns populated for recent weeks

## Dependency: `node-xlsx`

This is the project's first npm dependency.

- **Package**: `node-xlsx` (2 transitive deps, 0 vulnerabilities)
- **Why**: Parsing the EC's XLSX file. The alternative (`xlsx`/SheetJS) has known high-severity vulnerabilities. Manual XML parsing is possible but fragile for a 226-column, 1086-row sheet.
- **Already installed and tested**: the discovery script runs successfully

## Pipeline Design

### Step 1: `_scripts/fetch_eu_prices.mjs` (already created -- skeleton working)

The script is already implemented and tested. It:
- Downloads the 4.2 MB XLSX from the stable EC URL
- Parses with `node-xlsx`
- Matches target columns by header name (resilient to column reordering)
- Converts Excel serial dates to ISO strings
- Converts EUR/1000L to EUR/L
- Writes `_fuel-pdfs/eu_prices.csv`

**CSV output** (verified):
```
date,eu_euro95,eu_diesel,gr_euro95,gr_diesel,it_euro95,it_diesel,bg_euro95,bg_diesel,ro_euro95,ro_diesel
2005-01-03,1.042,0.936,0.749,0.756,1.116,1.018,,,,
...
2026-03-16,1.838,1.950,1.924,1.902,1.819,2.033,1.331,1.437,1.673,1.763
```

**Remaining work**: add short-circuit logic -- if `eu_prices.csv` already exists and its last date matches the downloaded data's last date, skip the write.

### Step 6: Frontend (`fuel-charts.js`)

Add `renderEUComparison(data)` function:

- Read `data.eu_comparison`; if missing, skip (graceful degradation)
- Render a single line chart with multiple series
- Greece is the anchor series (thicker line, primary color)
- EU average, Italy, Bulgaria, Romania as secondary series (thinner, muted)
- Country toggle pills: GR (pinned, always on), EU, IT, BG, RO
- Fuel selector: responds to the global `fuelState` (euro95/diesel only for EU data)
- If user selects 100 or LPG (not in EU data), the EU chart shows a disabled state or stays on the last valid fuel
- Range buttons: 1Y, 3Y, 5Y, All (weekly data benefits from longer ranges than daily)
- Tooltip: shows all visible countries' values for the hovered week

## Risks and Mitigations

| Risk | Mitigation |
|---|---|
| EC changes the XLSX URL | Stable URL (no date), unchanged for years; if it breaks, pipeline warns and proceeds without EU data |
| XLSX column order changes | We match by header name, not position |
| XLSX format changes entirely | Parsing isolated in `fetch_eu_prices.mjs`; swap implementation without touching the rest |
| 4 MB download on every daily run | Short-circuit when data hasn't changed (compare latest date) |
| Weekly vs daily frequency mismatch | EU chart uses its own timestamps array; no interpolation; rendered as weekly points |
| `node-xlsx` vulnerability in future | Minimal dependency (2 transitive deps); can vendor or replace if needed |
